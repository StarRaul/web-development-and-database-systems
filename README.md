# Web Development & Database Architecture Implementations

A suite of web applications and data persistence projects demonstrating databases, document-based NoSQL stores, hierarchical data structures, and dynamic backend logic using PHP and frontend tooling.

## Projects Included

### 1. MongoDB Document Store (`Proiect-mongo`)
Implementation of document schema modeling, aggregation pipelines, and CRUD transactions using MongoDB for handling unstructured or semi-structured data.

### 2. Secure Relational Database with PDO (`Proiect-pdo`)
A database access layer written in PHP utilizing PHP Data Objects (PDO) with prepared statements to enforce secure query execution, prevent SQL injection, and manage relational records in MySQL.

### 3. Full-Stack Web Application (`Proiect-web`)
An integrated web platform combining server-side PHP business logic with a dynamic, responsive user interface built using modern SCSS styling and client-side JavaScript.

### 4. Hierarchical Data Storage & Transformation (`Proiect-xml`)
Data parsing and transformation utility structured around XML standards, demonstrating document schema validation and styling transformations via XSLT.
